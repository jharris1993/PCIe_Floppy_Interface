# Tools

This directory contains version-controlled development and verification tooling used by the project.

`Codex_Skills/kicad-eda` is the maintained source for the locally installed KiCad EDA skill. Its installation is a copy; removing that copy does not remove this source.

`Codex_Skills/literal-action-authorization` is the maintained source for the personal interaction rule that interprets questions, imperative instructions, and ambiguous requests in context.
